\begin{abstract}
本文给出 PyQCU 面向 Wilson--Clover 传播子求解的高性能 MultiGrid 实现。
方法以奇偶 Schur 算子为细层问题，通过近零模、局部正交聚集和 Galerkin
投影生成递归粗层。Strict 路径采用
\(D_l=X_l+H_l\)、\(\widehat D_l=X_l^{-1}D_l\) 和
\(D_{l+1}=R_l\widehat D_lP_l\)，运行时保留完整粗层几何与
\(X/Y/\widehat Y\) 资产。CUDA--C++ 后端通过细层投影复用、粗层设备端
标量与融合内核、CUDA Graph、分块/着色 Galerkin、持久工作区、校验缓存、
rank-local halo 和非阻塞向量通信降低真实 wall time。性能评价严格采用
\code{git tag test27}：66 个精确 combined 单元、132 条 side record，
MG-2/3 在 35/44 个单元中优于 QUDA；正式 trace-off MG 为 21/22。
所有精确单元通过 full-operator 真残差门，最大观测显存低于 85\% 门限。
此外，本文给出 508 报告中的 64--1024 进程大格扩展数据，作为 PyQCU
早期 DCU 路径的独立历史证据。
\end{abstract}

\section{传播子、Dslash 与奇偶消元}

\subsection{Wilson 与 Clover}

规范链接 \(U_{x,\mu}\in SU(3)\) 连接相邻格点。取 Wilson 参数 \(r=1\)，
裸跃迁核和 Wilson 算子为
\begin{align}
 (H\psi)_x
 &=\sum_{\mu=0}^{3}\left[
 (1-\gamma_\mu)U_{x,\mu}\psi_{x+\hat\mu}
 +(1+\gamma_\mu)U^\dagger_{x-\hat\mu,\mu}\psi_{x-\hat\mu}
 \right],\\
 D_W&=(m_0+4)I-\frac{1}{2}H
 =(m_0+4)(I-\kappa H),
 \qquad
 \kappa=\frac{1}{2m_0+8}.
\end{align}
PyQCU 的求解器使用归一化形式
\(D_{\mathrm{pc}}=I-(\kappa/u_0)H\)，当前 C++ 生产路径等价于
\(u_0=1\)。C++ 原始 Dslash 入口返回裸核 \(H\)，不含单位项和
\(-\kappa\) 因子。

Clover 项由四点规范环构造：
\begin{align}
 Q_{\mu\nu}&=P_{\mu\nu}+P_{\nu,-\mu}
 +P_{-\mu,-\nu}+P_{-\nu,\mu},\\
 C_{\mu\nu}&=Q_{\mu\nu}-Q^\dagger_{\mu\nu},\\
 T_p&=-\frac{\kappa c_{\mathrm{sw}}}{8u_0}
 \sum_{\mu<\nu}\gamma_\mu\gamma_\nu C_{\mu\nu},
 \qquad
 A_p=I_p+T_p.
\end{align}
当前有效 \(c_{\mathrm{sw}}=1\)。Clover 项是 onsite \(12\times12\)
spin--color block，不扩大最近邻 stencil。

\subsection{奇偶 Schur 消元}

将场分为 even 和 odd 两个子空间，完整块算子为
\begin{equation}
 D_{\mathrm{pc}}=
 \begin{pmatrix}
 A_e & -\kappa H_{eo}\\
 -\kappa H_{oe} & A_o
 \end{pmatrix}.
\end{equation}
以奇数子格 Schur 补为例：
\begin{align}
 S_o&=A_o-\kappa^2H_{oe}A_e^{-1}H_{eo},\\
 b_o^{\mathrm{pc}}&=b_o+\kappa H_{oe}A_e^{-1}b_e,\\
 x_e&=A_e^{-1}\left(b_e+\kappa H_{eo}x_o\right).
\end{align}
这是精确消元。外层 Krylov 迭代只作用于半体积未知量，最终仍使用完整
Wilson/Clover 算子的真残差判定收敛。

\section{MultiGrid 算法}

\subsection{近零模、转移和 Galerkin 粗算子}

设第 \(l\) 层算子为 \(A_l\)，近零模满足
\begin{equation}
 A_lB_l\approx 0.
\end{equation}
在每个 aggregate 内对 \(B_l\) 做局部正交化得到延拓 \(P_l\)，并令
\begin{equation}
 R_l=P_l^\dagger,\qquad
 P_l^\dagger P_l=I,\qquad
 A_{l+1}=R_lA_lP_l.
\end{equation}
\(P_lP_l^\dagger\) 不是细层单位算子；粗空间只消除 \(P_l\) 能表示的
低模误差。代表性粗层维度若为 \(EN_c\)，显式稠密存储需要
\(O((EN_c)^2)\)，因此运行期只保存有限支撑 block/stencil。

\subsection{预条件 Bi-CGStab}

\begin{algblock}{Preconditioned Bi-CGStab:
\(\text{solve }M^{-1}Ax=M^{-1}b\)}
\label{alg:bicgstab}
\small
\begin{tabular}{@{}>{\raggedright\arraybackslash}p{0.91\textwidth}@{}}
\toprule
\(\mathbf{Input:}\;A,\;b,\;x^{(0)},\;M,\;\varepsilon\)\\
\(r^{(0)}=b-Ax^{(0)},\qquad \tilde r=r^{(0)}\)\\
\(\mathbf{for}\;i=1,2,\ldots\)\\
\(\quad \rho_{i-1}=\tilde r^\dagger r^{(i-1)}\)\\
\(\quad \mathbf{if}\;\rho_{i-1}=0\;\mathbf{then\;fail}\)\\
\(\quad \mathbf{if}\;i=1\;\mathbf{then}\;
 p^{(1)}=r^{(0)}\)\\
\(\quad \mathbf{else}\;
 \beta_{i-1}=\dfrac{\alpha_{i-1}\rho_{i-1}}
 {\omega_{i-1}\rho_{i-2}};
 p^{(i)}=r^{(i-1)}
 +\beta_{i-1}\left(p^{(i-1)}-\omega_{i-1}v^{(i-1)}\right)\)\\
\(\quad \text{solve }M\hat p=p^{(i)};\quad v^{(i)}=A\hat p\)\\
\(\quad \alpha_i=\dfrac{\rho_{i-1}}{\tilde r^\dagger v^{(i)}};
 s=r^{(i-1)}-\alpha_i v^{(i)}\)\\
\(\quad \mathbf{if}\;\|s\|/\|b\|\le\varepsilon\;\mathbf{then}\;
 x^{(i)}=x^{(i-1)}+\alpha_i\hat p;\ \mathbf{stop}\)\\
\(\quad \text{solve }M\hat s=s;\quad t=A\hat s\)\\
\(\quad \omega_i=\dfrac{t^\dagger s}{t^\dagger t}\)\\
\(\quad r^{(i)}=s-\omega_i t;\quad
 x^{(i)}=x^{(i-1)}+\alpha_i\hat p+\omega_i\hat s\)\\
\(\mathbf{end\,for}\)\\
\bottomrule
\end{tabular}
\end{algblock}

\subsection{PyQCU Strict 粗层分解}

Strict 路径将粗层算子拆成
\begin{equation}
 D_l=X_l+H_l,\qquad
 \widehat D_l=X_l^{-1}D_l,\qquad
 D_{l+1}=R_l\widehat D_lP_l.
\end{equation}
轴链接资产满足
\begin{equation}
 \widehat Y^{f}_{l,\mu}=X_l^{-1}Y^{f}_{l,\mu},
 \qquad
 \widehat Y^{b}_{l,\mu}=Y^{b}_{l,\mu}X_l^{-\dagger}.
\end{equation}
细层是 compact target-parity 问题，粗层保留 full geometry。运行时
常规求解驻留 \(X,X^{-1},\widehat Y\)；raw \(Y\) 只用于 setup 或诊断。

\section{CUDA--C++ 实现}

\subsection{细层与粗层瓶颈}

Wilson Dslash 单次应用读取八个邻居。\(1\pm\gamma_\mu\) 把四分量
spinor 投影为两个分量，再执行 \(SU(3)\) 矩阵乘法和累加。时空维尾置
有利于合并访存。粗层相反，向量较小但内核启动、标量复制、点积、
全局归约和同步会主导 wall time。

CUDA--C++ 后端采用以下优化：
\begin{itemize}
  \item 将 \(\alpha,\beta,\omega,\rho\) 等标量保留在设备端
        \code{device_vals}，减少主机往返；
  \item 融合 \(\beta/\rho\)、\(r/x\) 等元素更新，减少内核数；
  \item 对固定粗层 Bi-CGStab 段使用 CUDA Graph，降低 launch 开销；
  \item 对小最粗层使用 cooperative fused solve，过大时安全回退；
  \item 使用持久 hierarchy、递归 arena 和外部 FGMRES workspace；
  \item runtime cache 记录 shape、dtype、identity 和逐 tensor SHA256。
\end{itemize}

\subsection{Setup 与显存}

Galerkin 构造按 source 着色并分批执行，根据 workspace cap 自动选择
batch 大小。Strict 缓存使用 HDF5 保存 blocked basis、onsite inverse
和 \(\widehat Y\)，读取前校验每个 tensor，写入使用临时文件和原子发布。
若 setup 无法摊销到足够求解次数，MG 即使减少外层迭代也未必获得端到端
加速。

\subsection{分布式粗层通信}

每个 rank 只持有本地粗块，halo 只交换活跃 face。c64 vector halo 使用
\begin{equation}
 \text{active-face pack}
 \parallel\text{local base kernel}
 \rightarrow
 \text{nonblocking MPI}
 \parallel\text{local tail}
 \rightarrow
 \text{remote correction}.
\end{equation}
complex64 默认启用 overlap；complex128 改变浮点累加顺序后曾由 32 次
外层迭代退化到 451 次，因此默认关闭，只有显式开关并重新通过大格真残差
门后才允许启用。当前 link halo 仍使用阻塞式 \code{Sendrecv}。

\section{讨论与结论}

\begin{enumerate}
  \item V100 上 MG 优势最明显，c64/c128 MG-3 trace-off 中位数分别
        为 4.74 和 3.22。
  \item 双 P100 在 trace-off 下总体有利，但 MG-2/3 中位数仅为
        1.15--1.79，且大格容量受显存与 setup 时限限制。
  \item BiCGStab reference 为 0/22，说明优势来自 MG，不是全部求解器。
  \item 最大真残差满足门限；PyQCU 最大观测显存约为 QUDA 的一半。
  \item 508 报告证明早期 DCU 大规模扩展能力，但不能替代当前
        Strict-MG 的正式性能边界。
\end{enumerate}

下一阶段应聚焦 coarse solve、残差检查、全局归约和 setup 显存，
继续推进 device-aware MPI、持久 request、混合精度策略与国产加速器
端到端验证。
