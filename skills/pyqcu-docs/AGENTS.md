# AGENTS.md — pyqcu-docs

PyQCU 正式文档导航与技能化提取技能。`docs/**` 是规范源，`skills/**` 只保存
可复用摘要、执行不变量和来源映射。

- 规范全文：`SKILL.md`
- 文档职责与主责技能：`references/project-docs-map.md`
- 已蒸馏工程知识与全部文档结论覆盖索引：`references/extracted-guidance.md`
- Read the Docs 双语站点约定与发布检查单：`references/readthedocs-release.md`
- 结构与覆盖回归：`scripts/audit-docs-skills.py`
- 只有新增/删除技能目录才同步库级 `../AGENTS.md` 技能表与计数；不自动提交或推送。
