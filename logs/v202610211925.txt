### S2 — CUDA local stencil flattened gather 与 W=8
- 根因: `BatchedLocalSchur._slicem` 逐 K 窗口执行 host assignment/高级索引，产生多次 kernel dispatch 与 `.item()` 同步。
- 修改:
  - 新增 `_flat_window_index([K,4,W]) -> [K,W^4]`。
  - `_slicem` 使用 expanded base + `torch.gather`，一次复制全部 K 窗口。
  - 每次 `BatchedLocalSchur.__call__` 只构造一次索引，10 个 matrix slice 复用。
- V100 microbenchmark，生产矩阵 shape `[12,12,24,24,24,32]` c64:
  - K=1 non-wrap: `1.105 -> 0.241 ms`，4.58x。
  - K=4 non-wrap: `4.027 -> 0.272 ms`，14.81x。
  - K=8 non-wrap: `7.933 -> 0.430 ms`，18.47x。
  - wrap K=4/8: `4.024 -> 0.284 ms` / `7.977 -> 0.443 ms`。
  - 所有样本 `torch.equal=true`。
- W 窗口:
  - 生产 local-op 中位 `W=10 27.337 ms`、`W=8 13.725 ms`、`W=6 13.280 ms`。
  - `W=8` 通过 full-grid 与内部/周期边界回归；`W=6` 在非平凡 CPU matrix fixture 上出现局部元素不符，因此拒绝。
  - 生产入口采用 `W=8`。

### S4 — KUPL legacy MG coarse tile 与 canonical conversion
- profiling: 147 次 fine application 约 27 s，47 次 coarse application 约 60 s，coarse 是主导项。
- 根因:
  - 每个 output/input component 重复四方向查找与 32-direction scan。
  - coefficient stream 的 site-major 页面访问跨度过大。
  - canonical/full 转换使用 component-major 四维除法。
  - coarse correction 后立即重复应用全算子重算同一 residual。
- 修改:
  - `apply_multigrid_coarse_dslash_wide` 以 512-site tile 预解析 32 个 neighbor view，按 coefficient stream 连续累加。
  - crossing 直接映射 halo direction，不扫描 32 方向。
  - canonical/full 转换改走 half-site，并同时发出两个时间 parity。
  - `apply_coarse_correction` 返回刚形成的 fine residual norm，去掉重复全算子。
  - verbose 模式增加最终 native residual/target/relative 记录。
- 最终 4-rank 两样本: `28.69636658 / 31.18712904 s`，median `29.94174781 s`。
- 原同口径 `94.10767782 s`；降低 68.18%，speedup 3.143x。
- 60 iterations，native relative residual `9.70132e-7`，verifier=0。
- rank0 resident RSS `2.155 GB`，max RSS `2.969 GB`。

# Stage 13：CUDA stencil gather/W=8 与 KUPL coarse tile512 优化报告

## 结论

本轮同时优化 CUDA 与 KUPL：CUDA MC 的 33-tensor stencil 改为 flattened periodic gather，并将安全 local 窗口从 W=10 收紧到 W=8；KUPL legacy MG 将 coarse dslash 改为 512-site tile/streaming coefficient，并消除 canonical conversion 与 coarse-correction 的重复工作。

CUDA 生产 cold setup 从 `616.343 s` 降到 `327.587 s`，降低 46.85%；其中 stencil 从约 `598.107 s` 降到 `323.745 s`，降低 45.87%。KUPL 4-rank legacy MG 从 `94.108 s` 降到中位 `29.942 s`，降低 68.18%，但仍比 Schur BiCGStab fallback 的 `5.515 s` 慢。

## CUDA 优化

`_slicem` 旧路径逐 K 窗口执行 assignment 或高级索引。新路径一次生成 `[K,W^4]` 周期索引，以 expanded base + `torch.gather` 完成全部窗口，并在一次 local operator 调用中复用索引。

V100 gather microbenchmark（生产矩阵 c64）：

| K / 边界 | 旧 | 新 | speedup |
|---|---:|---:|---:|
| K=1 internal | 1.105 ms | 0.241 ms | 4.58x |
| K=4 internal | 4.027 ms | 0.272 ms | 14.81x |
| K=8 internal | 7.933 ms | 0.430 ms | 18.47x |
| K=4 periodic | 4.024 ms | 0.284 ms | 14.19x |
| K=8 periodic | 7.977 ms | 0.443 ms | 17.99x |

生产 local Schur 窗口取 W=8。full-grid 与周期边界测试通过；W=6 已被非平凡矩阵回归拒绝。真实 cold stencil 为 `323.745 s`，20 次 MG 真残差 `4.1247345e-7`。
