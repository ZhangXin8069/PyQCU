0.1.3 bugfix release (2026-11-09)
-------------------------------
Fixes:
- `--lattice` with a non-even extent now prints a clean argparse error (or a
  JSON `status=FAIL` object with exit 2), instead of a traceback.
- `_selftest.run_all(include=())` is rejected; `include="torch"` is accepted as
  one layer instead of being split into characters.
- Torch self-test is deterministic: seeded source plus a zero initial guess.
- KUPL/CUDA `iterations=None` is accepted and printed as `n/a`;
  `int(None)` no longer fails.
- A corrupt native library is now FAIL, not SKIP: KUPL only skips on
  `FileNotFoundError`; CUDA only skips on `ModuleNotFoundError`/missing bridge.
- Native C stdout is captured at fd 1 and `fflush(NULL)` runs before restore,
  so `--json` stays parseable even with CUDA `printf` banners.
- `setup.py` forces `KUPL_BUILD_TESTS=OFF` for Python builds; an inherited
  `ON` can no longer break an sdist build against pruned test sources.
- Docstring/comment literals with LaTeX backslashes use raw strings; fresh
  `-OO` compilation no longer emits `SyntaxWarning`.
- `release_check.py` records a parse failure for malformed PyPI JSON instead
  of raising.
