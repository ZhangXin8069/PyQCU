## 关键日志
### S1 — CUDA legacy Clover BiCGStab 成对归约
- 目标: 将单 rank sync-light 循环中的 `t^H s` 与 `t^H t` 两次 cuBLAS 点积合并，减少启动和 `t` 读取开销，同时保持任意 12x12 Clover 矩阵语义。
- 操作: 新增 `bistabcg_dot_pair_complete`；每个 block 同时累加两个点积，最后一个 block 按固定 partial 顺序汇总；completion counter 每轮异步清零，不使用浮点 atomicAdd。
- 基线: 两轮 ABBA、每轮 2 warmup + 10 steady，真实 LIME 统一输入，中位 `0.161293 s`，MAD `0.001219 s`，18 iterations，独立真残差 `6.695186e-7`。
- 候选: 同热态两轮 ABBA，中位 `0.157776 s`，MAD `0.003917 s`，18 iterations，独立真残差 `6.694990e-7`。
- 结果: 降低 `2.18%`，加速 `1.0223x`；库 SHA256 由 `c9c09991...` 变为 `8c37f6afefe4dc24bc9942647391083f58b391eb29c917960178d891ac21422a`。
- 边界: 多层 MG 后端两轮中位均为 `0.1746 s`，生命周期 `0.417192 -> 0.414053 s`，20 iterations、真残差 `4.124735e-7`；不可把 BiCG 收益外推为 V-cycle 提速。

### S2 — KUPL legacy-MG BiCGStab 成对归约
- 目标: 合并 `bicgstab_chunk` 的 `(v,v)` 与 `(v,s)` 全局归约，降低多 rank 串行集合通信。
- 操作: 新增 `mg_dot_pair`，同一 OpenMP 遍历计算两个局部点积，并用一次四实数组 `MPI_Allreduce` 汇总；更新公式、停机、adaptive correction 和 actual iteration counting 不变。
- 基线: 生产 `24^3x64` c64、4 ranks x 4 threads、grid `1x4x1x1`、restart=5、deflate，三轮 `18.501/18.987/16.637 s`，中位 `18.501 s`。
- 候选: 同配置三轮 `17.770/17.725/16.747 s`，中位 `17.725 s`。
- 结果: 降低 `4.19%`，加速 `1.0438x`；均 47 iterations，native relative residual `9.138e-7`，verifier=0，峰值 RSS 约 `2.83 GiB`，resident 约 `2.06 GiB`。
- 边界: 每轮集合归约从 6 降到 5；该收益来自通信与循环融合，不代表 coarse-dslash 算术量下降。

# Stage 16：CUDA/KUPL 成对归约与三方性能报告

## 结论

本阶段保留两个低风险、可验证的改动：

1. CUDA QCU legacy Clover BiCGStab 将 `t^H s` 与 `t^H t` 合并为一次确定性 GPU 成对归约。真实生产 Clover BiCGStab 中位 `0.161293 -> 0.157776 s`，降低 `2.18%`，18 iterations 与真残差门禁不变。
2. KUPL QCU legacy-MG BiCGStab 将 `(v,v)` 与 `(v,s)` 合并为一次四实数组 `MPI_Allreduce`。生产 4-rank MG 中位 `18.501 -> 17.725 s`，降低 `4.19%`，47 iterations、verifier 和 native residual 门禁不变。

CUDA MG 后端本身没有可辨识提速：baseline 与 candidate 的 20 样本合并中位均为 `0.1746 s`。因此本阶段 CUDA 改动定位为 null-vector/BiCG 构建优化，不宣称 V-cycle 加速。

## CUDA 根因与实现

原单 rank sync-light 路径在每轮尾部连续执行两次 cuBLAS 复点积，输入左侧均为 `t`。新增 kernel 同时计算：

- `t^H s`
- `t^H t`

每个 CUDA block 在寄存器中计算两个局部和，在 shared memory 做树形归约，partial 写入临时区；最后完成的 block 按固定索引顺序做第二级树形归约，直接写 `device_vals`。completion counter 每轮由 `cudaMemsetAsync` 清零，避免浮点 atomicAdd 的非确定性。multi-rank 的五流参考路径和 Clover 12x12 乘法语义未改变。

## KUPL 根因与实现

`bicgstab_chunk` 中两个相邻点积输入相同、互相独立，却各自产生局部并行区域和全局 `MPI_Allreduce`。`mg_dot_pair` 在同一 OpenMP 循环中同时累加 `v^H v` 与 `v^H s` 的四个实分量，然后一次 `MPI_Allreduce(count=4)`。每轮全流程集合归约数由 6 降到 5，更新公式、停机、adaptive correction 与真实完成迭代计数均不变。

coarse-dslash 微基准还测量了 tile 大小：256-site `0.09049 s`、512-site `0.08405 s`、1024-site `0.07733 s`。1024 虽让孤立 kernel 快约 8%，但每次仅节省约 `6.7 ms`，远小于配对归约的生产收益，故恢复 512，只保留一个最小改动。
