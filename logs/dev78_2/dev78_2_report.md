## 3. 测量协议与残差数据源

约定参数（与 test12/dev78_1 一致）：mass=0.05, atol=1e-6, gauge_seed=42,
κ=1/(2m+8)=0.0617284, E=48, NV_ITERS=2, MG_GRID=[2,2,2,2]。

- **加速比语义**：multi_ref_wall = max(各线程 ref_time)（多线程 BiStabCG 墙钟）；
  multi_mg_wall = max(各线程 mg_time)；speedup = multi_ref_wall / multi_mg_wall。
  计时仅求解阶段（不含 setup/粗算子构建）。
- **数据持久化**：全部 h5py（save_dict_h5/load_dict_h5，独立 File 句柄多线程安全）。

**迭代残差数据源（dev78_2 新增 conv 子命令）**：
- **MG 残差（C++ 实测）**：C++ 端每次 `applyCloverMultigridQcu` 求解无条件
  把逐 V-cycle 迭代残差数组写入 `REPO/logs/clover_multigrid.log` 的
  `CONVERGENCE_HISTORY: [r0,r1,...]` 行（lattice_clover_multigrid.h:1673）。
  conv 子命令按文件偏移增量解析，与测量一一对应；多线程时每线程一条，均保留。
- **参考 BiStabCG 残差（Python 复现）**：C++ stdout 只输出收敛点
  （PRINT_MULTI_GPU_CLOVER_BISTABCG 默认关闭，lattice_clover_bistabcg.h:10）。
  完整曲线用同一 Schur 算子 + 同一 BiStabCG 算法在 torch 上复现
  （`_bistabcg_history`，dev73_5 已验证方案，数学等价、零 C++ 改动）。
- 收集方式：21 个去重配置（bench 7 + sweep 16 + verify 3 去重）各跑一次
  共享模式测量，逐条解析残差 → `dev78_2_conv.h5`（含每配置 speedup 与
  残差曲线）。

### 7.2 收敛行为解读

1. **全部 21 配置 MG 与 ref 均收敛至 < 1e-6**（atol 达成），无发散/伪收敛。
2. **MG 相对 ref 的迭代优势**：8x8x8x16 上 MG 30-120 次收敛 vs ref 90 次
   （3L 配置 30-56 次，2L 配置 55-120 次）；大格子 16x16x16x16 2L 114 次
   （r20 时 V-cycle 频率低，与 speedup<1 对应）。
3. **多线程一致性**：P100×2 配置的 2 条 MG 曲线（每线程一条）迭代数与
   残差路径相同（收敛曲线重合）——残差层面再次佐证线程间一致性
   （与 verify 的 rel_diff=0 一致）。
4. **参数-收敛联动**：ct1e4（粗层容差松）→ 校正弱 → 迭代数多
   （如 L2 r10 ct1e4 cmi10 达 120 次）；ct1e5 + cmi15 → 迭代数少且
   speedup 高（L3 r10 ct1e5 cmi15 45 次 / 2.43）。cmi10 时粗层迭代上限
   不足（10 次 < 通常 15-20 次收敛所需），部分配置迭代数偏大。
5. **V-cycle 结构**：收敛曲线呈典型"平台-骤降"阶梯（粗层校正后细层
   残差骤降），平台长度 ≈ num_restart（V-cycle 频率）——r10 配置平台
   长于 r5，但校正更充分（粗层容差紧时总迭代更少）。

## 11. 结论与遗留

**结论**：
1. dev78_2 完整复测确认 dev78_1 成果：bench 中位 1.411、best 2.303、
   sweep 13/16≥1.5 best 2.413、verify 全 PASS。
2. **全求解器迭代残差图补全完成**：21 配置的 MG 实测残差（含多线程各
   线程曲线）与参考 BiStabCG 复现残差全部成图（29 张），且全部收敛
   < 1e-6 —— 正确性从"终态一致"深化到"收敛路径一致"。
3. 收敛路径分析印证参数优化机理：ct/cmi 决定粗层校正质量，r 决定
   V-cycle 频率，二者联动决定 MG 总迭代数与加速比。

**遗留**：
- 16x16x16x16 2L r20=0.700 仍 <1（层数固有特性，coarse solve 开销主导）。
- conv 的 ref 曲线为 Python 复现（与 C++ 数学等价，但非 C++ 直接输出；
  C++ PRINT 宏关闭时无法直采，已在 §3 说明）。
- sweep 中 3 个 <1.5 配置（r5+ct1e4 组合）为参数空间已知弱区，非回归。
- 16x16x16x64 未实测（仅预算模型，88% 上限有风险）。
