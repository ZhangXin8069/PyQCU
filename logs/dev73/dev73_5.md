# dev73_5 —— CUDA-C++ Clover MultiGrid 性能结果扩展报告

> 扩展 `logs/dev73/mg-v4-report-2026-08-02` 的性能结果：不同精度 / 格子大小 / 求解器参数，
> 每配置附 BiStabCG 对照（收敛历史、计算热点、正确性检查）。
> LaTeX 版：`logs/dev73/dev73_5.tex` → `logs/dev73/dev73_5.pdf`。

## 保持一致的变量（与 v4 报告相同）

- 参考求解器 = `applyCloverBistabCgQcu`（奇偶预条件 Schur BiStabCG，VERBOSE=0）
- MultiGrid = `applyCloverMultigridQcu`（Schur-一致，多层粗层，null_vecs 缓存）
- mass=0.05, atol=1e-6, gauge_seed=42, κ=1/(2m+8), sigma=0.1, nv_iters=2, E=48
- 默认格子 {8,16,16,16}（各向均不小于）

## 测量协议（干净测量）

每个配置在独立进程中完成；参考 BiStabCG 与 MG 交叉计时（ref,mg,ref,mg,…），
各取 5 对的最小值/中位数（GPU：Tesla V100-SXM2-32GB，WSL2）。

## 与 v4 最终结果的一致性

- 8x8x8x16 加速比 2.43x（c64）/ 1.97x（c128），复现 v4 的 2.07–2.10x / 1.92x
- 默认格子 MG 耗时 399ms（与 v4 的 394ms 一致）；参考 BiStabCG 本会话更快
  （464ms vs v4 的 549ms，GPU 时钟），故加速比 1.16x 处于 v4 自记录的 0.98–1.40x 区间
- 解一致（vs_ref ~3.2e-7 c64 / 2.4e-8 c128）；细层迭代数 89 vs 86（v4：88 vs 86）
- c128 在默认格子上加速比 <1（双精度粗层求解开销主导，0.73x）；在更小的 8x8x8x16 上
  达标（1.97x，复现 v4）
- 规模效应：加速比随格子增大而下降且非单调
  （8x8x8x16 2.43x → 默认 1.16x → 8x16x16x32 1.11x → 16x16x16x16 0.81x）
