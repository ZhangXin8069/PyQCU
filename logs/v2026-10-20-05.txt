## 关键日志
### S1 — Csw 接入与 ABI 加固
- 目标: 让 QCU/PyQCU 与 PyQUDA/QUDA 的 `csw` 约定一致，并贯通 LIME 元数据。
- 关键改动: `argv` 扩展为 8 槽，槽 7 为 `_CSW_`；Clover onsite 系数统一为 `-kappa*csw/8`；单/多 GPU、Python 参考、MultiGpuMultigrid、single tests、PyQUDA 对照均传播 Csw。
- 关键修复: `testCloverDslashQcu` 改用 `clover_coefficient()`；五层 MG 容差边界不再读取 Csw；MG cache key 加入 mass/csw/seed/输入几何。
- ABI 门禁: Cython 校验 params/argv/set_ptrs 长度、dtype、device、contiguous、mass/atol/csw；`applyInitQcu` 声明 `except + nogil`，Cython 扩展以 C++ 编译。

### S2 — QcuRuntime 与 simple 对照
- `QcuRuntime` 只复用 `set_ptrs[0:30]`，保留 coarse 槽；统一 `init -> operation/getter -> end -> next slot`，并拒绝重入/并发。
- simple QCU/QUDA 共用同一 RHS，使用独立新报告名，校验各自收敛状态并比较归一化解差；旧 `PASS` 报告和 `SKIP` 返回值不能污染结果。
- `csw=0` 的 QUDA 路径切换 Wilson Dirac；QCU/QUDA 的 PASS 绑定 `max(atol, precision floor)` 真残差判据。

### S3 — 独立 KUPL MPI+OpenMP 后端
- 在 `cpp/kupl/qcu` 独立实现 C++17 MPI+OpenMP 后端，不 include/link CUDA QCU。
- 实现核心 Clover/Wilson dslash、Schur BiStabCG/CG、Clover prepare/reconstruct、Laplacian、Gaussian SU(3)、restrict/prolong、窄/宽 coarse 33-stencil dslash。
- Clover BiStabCG 改为 CUDA 同构的 selected-parity Schur 系统；非有限或超容差真残差 fail closed。
- `set_ptrs[100]` 按槽位隔离 backend 生命周期；Python ctypes 暴露全部 37 个 ABI 名称，未实现项沿 C++ 层显式失败。
- NUMA/OpenMP 绑定按 shared-memory local rank 分配，跨节点仍使用全局 Cartesian rank；`KUPL_NUMA_BIND=1` 与 `OMP_PROC_BIND` 冲突时初始化显式拒绝。
- halo face/corner 打包由全体积扫描改为仅边界元素；MPI request vector 复用；coarse halo 使用 32 方向非阻塞交换。
