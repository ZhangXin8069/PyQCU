--- report begin ---
已完成 pyqcu/testing/simple/mpi 小格点 MPI 版本。

改动内容:
- 新增统一启动器 solve_case.py 和 worker.py，支持 KUPL 与 CUDA 两个后端。
- KUPL 使用真实四维 MPI 分域与 rank 内 OpenMP；MPI 负责绑定时设置 KUPL_NUMA_BIND=0。
- CUDA 使用 one-rank-one-GPU 的四维 MPI 分域，区别于单进程 MultiGpuMultigrid 整题复制模式。
- 直接接受 PyQUDA/QIO LIME，按魔数识别，支持大小写扩展名、Scidac 私有/公共 record XML、clovCoeff 与 Mass。
- 自动切出 8x8x8x16 小体积，生成共享 source，按需构建 33-tensor 粗算子缓存，并输出包含 MPI 几何、绑定、计时、独立真残差的 JSON。
- 新增契约测试和 README/AGENTS 说明。

推理依据:
- KUPL 已具备 MPI halo、分布式双线性形式和 openmp 后端，因此新入口复用 kupl_multigrid.py。
- CUDA legacy MG 需要全局粗算子，启动器先构建一次，各 rank 只读取局部粗格超切片。
- OpenMPI 4.1 不允许 --bind-to numa 与 map-by pe=N 组合，因此使用 OMP_NUM_THREADS 固定线程数并采用 ppr:1:numa；rank 数超过本机 NUMA 域时自动回退 bind-to none。
- LIME 子体积保留原 gauge link，切口缝不周期，因此仅用于实现和数值正确性验证。

- CUDA 2 MPI ranks, 8x8x8x16: PASS，独立真残差 2.0365e-07。
- KUPL/CUDA 解相对 L2 差 2.1068e-06。
- git diff --check: PASS。
- form audit: PASS。
